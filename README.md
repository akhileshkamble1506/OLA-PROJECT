A dynamic, interactive Power BI data visualization tool built to explore operational ride-sharing data—focusing on booking success rates, vehicle-specific performance, revenue channels, and cancellation trends.

🎯 Short Description / Purpose
The Ola Analytics Dashboard is a visually engaging Power BI report designed to help users analyze over 100,000 ride bookings and 57M in booking value recorded during July 2024. The dashboard highlights critical business metrics such as payment method preferences (Cash vs. UPI), specific driver and customer cancellation reasons, and vehicle category ratings. This tool is intended for use by business analysts, operations managers, and data-driven strategists who seek to understand ride-sharing efficiency, revenue streams, and customer satisfaction.

🛠️ Tech Stack
The dashboard was built using the following tools and technologies:

🗄️ SQL Server Management Studio (SSMS) - Used as the primary database management environment to host and manage the OLA_PROJECT database.

🔍 SQL - Used for backend data extraction, aggregation, and creating optimized database views (e.g., successful bookings, cancellation reasons, top customers, and average ratings) prior to dashboard integration.

📈 Power BI Desktop - Main data visualization platform used for report creation and interactive dashboard design.

🧹 Power Query - Data transformation and cleaning layer used to further prepare, format, and structure the data within Power BI.

🧮 DAX (Data Analysis Expressions) - Used to create calculated measures, dynamic visuals, and conditional logic directly within the report.

🔗 Data Modeling - Relationships established among tables to enable seamless cross-filtering and accurate aggregations across all visuals.
